# Etapa 0 — Base: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Esqueleto mínimo de la PWA con pruebas (`node --test`), linter (ESLint), servidor local y README.
**Architecture:** Archivos estáticos servidos desde la raíz del repositorio, sin paso de construcción. Las pruebas leen los archivos con `node:fs`.
**Tech Stack:** HTML, JS (módulos nativos), Node ≥ 20 (`node --test`), ESLint, `python3 -m http.server`.
**Spec:** `docs/superpowers/specs/2026-11-23-etapa-0-base-design.md`

## Global Constraints
- Sin dependencias de ejecución; solo `eslint`, `@eslint/js` y `globals` como `devDependencies`, con versión exacta (`--save-exact`).
- Nombres de archivos y código en inglés; comentarios breves y textos visibles en español. Commits pequeños en español.
- Rutas relativas (`./`): la app debe funcionar servida en una subcarpeta (GitHub Pages: `/App-frances/`).
- Fuera de alcance: *service worker*, iconos, pantallas, `js/`, `css/`.

## Review Focus
1. App publicada en una subcarpeta: un `start_url` o `href` que empiece por `/` rompe la app → la prueba exige `"./"` y un `href` relativo (Tarea 2).
2. Acentos mal mostrados (é, ç, à): `index.html` debe declarar `<meta charset="utf-8">` → prueba (Tarea 2).
3. Vista en el móvil sin escala: debe existir `<meta name="viewport">` → prueba (Tarea 2).
4. Abrir `index.html` con doble clic (`file://`): el README explica que debe usarse `npm start` (Tarea 4).
5. Puerto 8000 ocupado o Node < 20: el README indica cómo usar otro puerto (`python3 -m http.server 8001`) y la versión de Node necesaria (`engines` en `package.json`) (Tareas 1 y 4).
