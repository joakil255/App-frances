# Etapa 1 — Esqueleto responsive y PWA: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cinco pantallas vacías con navegación por `#`, estilo Métro claro/oscuro, instalable y usable sin conexión, con aviso **Actualizar**.
**Architecture:** Archivos estáticos sin build. Lógica pura en `js/lib/` y `js/update.js`, probada con `node --test`; `sw.js` clásico probado dentro de `node:vm` con un entorno falso.
**Tech Stack:** HTML, CSS, JS (módulos), Service Worker, `node --test`, ESLint, `rsvg-convert` y `fonttools` (solo para generar iconos, una vez), GitHub Pages, PageSpeed Insights API.
**Spec:** `docs/superpowers/specs/2026-11-23-etapa-1-pwa-design.md` (y `DESIGN.md` para todo lo visual)

## Global Constraints
- Sin dependencias npm nuevas. Textos visibles en español; código y archivos en inglés; comentarios breves en español.
- Todo color, letra, tamaño y espacio sale de `DESIGN.md`. Texto de usuario siempre con `textContent`, nunca `innerHTML`.
- Rutas relativas en todas partes (la app vive en `/App-frances/`).
- Commits con `user.email` noreply (ya configurado); mensajes en español.
- Fuera de alcance: lógica de estudio, guardado de datos, selector de tema.

## Review Focus
1. Abrir la app sin conexión con una dirección con parámetros (`…/App-frances/?source=pwa`) → recibe `index.html` de la caché (Tarea 5).
2. Un archivo de la lista falta en el servidor (404) al instalar → la instalación falla y la versión anterior sigue funcionando (Tarea 5).
3. Peticiones a otros orígenes o que no son GET → el service worker no las toca (Tarea 5).
4. Primera instalación (sin controlador previo) → no aparece el aviso **Actualizar** (Tarea 6).
5. `controllerchange` llega dos veces o se pulsa **Actualizar** dos veces → la página recarga una sola vez (Tarea 6).
