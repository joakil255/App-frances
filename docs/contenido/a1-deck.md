## Lista REVISAR

Entradas de las que no hay total seguridad, con el motivo de la duda. Cuando las revises, cambia el contenido si hace falta y quita la marca «Revisar» al editarlas en la app. Después de corregir palabras del mazo, no pulses «Reemplazar» si vuelves a abrir «Añadir 100 palabras A1»: volvería a poner el texto original y la marca «Revisar».

| Francés | Motivo |
|---|---|
| désolé | Es la forma masculina: una mujer escribe «désolée». Decide si quieres también la forma femenina. |
| enchanté | Es la forma masculina: una mujer escribe «enchantée». Decide si quieres también la forma femenina. |
| l'enfant | «enfant» es masculino o femenino según el niño o la niña; aquí se marcó masculino. |
| le gâteau | En Chile «torta» suele ser la de cumpleaños y «queque» el bizcocho sencillo: elige la traducción que prefieras. |
| le petit déjeuner | También se escribe «petit-déjeuner» con guion; las dos formas se aceptan. El Quiz cuenta el guion: elige una. |
| le dîner | En Chile la comida de la noche se llama «la cena» o «la comida», y muchas familias toman «la once»: elige la traducción. |
